# HTML/CSS fallback (archived)

Plain HTML + CSS snapshot of the site (same look, no React). Kept as a lightweight alternative.

## Preview

Open `index.html` in a browser, or from the repo root:

```bash
npx --yes serve legacy-html
```

## Use as the main site

Copy `index.html` and `style.css` to the repo root, simplify `package.json` to Vite-only (or drop the build step and host the two files statically). See the previous static setup in git history if needed.
